# Security

If you find a vulnerability in Deez Project Manager, please report it privately.

- Prefer a [GitHub security advisory](https://github.com/DeaconDP/Deez-Project-Manager/security/advisories/new) when available
- Or email via [deac.online](https://deac.online)

Please do not open a public issue for security reports until a fix is available.

Do not commit secrets (tokens, private keys, `.env` files). Local project paths stay on your machine under the app data directory.
